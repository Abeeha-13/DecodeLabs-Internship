# DecodeLabs Project 1 — Rule-Based AI Chatbot

## Overview

This project is a simple Rule-Based AI Chatbot developed in Python as part of DecodeLabs Artificial Intelligence Project 1.

The chatbot uses predefined rules and conditional statements to respond to user inputs and simulate basic human-computer interaction.

## Features

* Handles greetings such as `hello` and `hi`
* Provides information about the chatbot
* Provides help and available options
* Provides basic support information
* Responds to `thanks` and `thank you`
* Supports exit commands: `exit`, `bye`, and `quit`
* Handles unknown user inputs
* Uses input normalization with lowercase conversion and whitespace removal
* Uses if-elif-else decision-making logic
* Runs continuously until the user exits

## Technologies Used

* Python
* Conditional statements
* While loop
* Dictionary
* Functions
* User input handling

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python chatbot.py
```

5. Enter a command when prompted.
6. Type `exit`, `bye`, or `quit` to close the chatbot.

## Example

```text
User: hello
Chatbot: Hello! Welcome to DecodeLabs support. How can I assist you today?

User: who are you
Chatbot: I am a Rule-Based AI Chatbot created for DecodeLabs Project 1.

User: help
Chatbot: You can ask me about help, options, or support.

User: support
Chatbot: For support, please contact the DecodeLabs team.

User: bye
Chatbot: Goodbye! Have a great day!
```

## Project Objective

The objective of this project is to demonstrate fundamental AI concepts through rule-based decision-making, control flow, and explicit programming logic.
