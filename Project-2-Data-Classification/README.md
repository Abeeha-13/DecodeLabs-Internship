# 🌸 Abeeha's Bloom AI

A machine learning web application that predicts the species of an Iris flower based on its measurements.

This project uses the K-Nearest Neighbors (KNN) algorithm with an interactive Streamlit interface.

## 🌿 Features

- Predicts Iris flower species
- Uses K-Nearest Neighbors (KNN)
- Feature scaling using StandardScaler
- Displays model accuracy
- Shows prediction confidence
- Interactive Streamlit user interface
- Displays Iris dataset information
- Explains how KNN works

## 🌸 Iris Species

The model can classify three Iris species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

## 📊 Dataset

The project uses the Iris dataset from Scikit-learn.

The dataset contains:

- 150 flower samples
- 4 features
- 3 flower species

### Features

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## 🧠 Machine Learning Model

**Algorithm:** K-Nearest Neighbors (KNN)

**K Value:** 3

The dataset is divided into:

- 80% Training Data
- 20% Testing Data

Feature scaling is performed using `StandardScaler`.
